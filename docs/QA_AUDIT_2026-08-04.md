## Hallazgos

### Resuelto — `npm test` mezclaba pruebas E2E con Vitest

**Estado:** resuelto.

`vitest run` detecta `frontend/e2e/critical-flows.spec.ts` y trata de ejecutar `test()` de Playwright. El resultado es: `Playwright Test did not expect test() to be called here`.

**Impacto:** la batería unitaria frontend no puede finalizar en local ni en CI usando el script actual, aunque los dos tests unitarios existentes sí pasan.

**Corrección aplicada:** `npm test` usa `vitest run --exclude e2e/**`; Playwright queda exclusivamente bajo `npm run test:e2e`. La validación posterior aprobó lint, 2/2 pruebas unitarias y build.

### Resuelto — Cobertura de alertas operativas sin prueba dedicada

**Estado:** resuelto.

`apps.notifications.monitoring` contiene reglas para tiempo excedido y trazabilidad pendiente de OT, con avisos tanto al técnico como a administradores. No se encontró un `test_*.py` específico que demuestre esos dos escenarios ni su deduplicación.

**Impacto:** una regresión en el cálculo de horas o en la fecha de programación podría llegar a producción sin detección automática.

**Corrección aplicada:** se añadieron tres pruebas automatizadas: exceso de horas con deduplicación, trazabilidad pendiente y OT cerrada sin alertas. Las tres pasan en Docker.

### P2 — Matriz visual y responsive incompleta

**Estado:** pendiente por entorno.

Las pruebas Playwright están configuradas, pero Chromium no está instalado localmente. Se hizo una comprobación manual limitada a 360 px; aún no se validaron en forma repetible login, QR público, reporte y los anchos 390, 768, 1024 y 1440 px.

**Impacto:** no es posible certificar el aspecto móvil pese a que el build y los componentes compilados son correctos.

**Corrección recomendada:** ejecutar `npx playwright install chromium` y después `npm run test:e2e`; guardar capturas de fallo como artefactos de CI.

### Resuelto — Advertencias de calidad frontend

**Estado:** resuelto.

El lint informa tres advertencias:

- Exportación mixta en `src/app/router.tsx` que afecta Fast Refresh.
- Dependencia `refresh` omitida en `NotificationCenter.tsx`.
- Dependencia `load` omitida en `NotificationsPage.tsx`.

**Impacto:** riesgo de cierres obsoletos en los efectos de notificaciones y experiencia de recarga menos fiable durante desarrollo.

**Corrección aplicada:** las cargas de notificaciones se estabilizaron con `useCallback` y se corrigió el auxiliar del enrutador. `npm run lint` termina sin advertencias.

## Observaciones de ejecución

- Los contenedores temporales no comparten `/tmp`; por eso una consulta posterior no puede reutilizar una base SQLite creada por otro `docker compose run`. Las pruebas se ejecutaron completas en un solo contenedor y no afectaron PostgreSQL operativo.
- La suite completa anterior con `--keepdb` no es determinista porque una prueba de reemplazo de taxonomía modifica el bootstrap persistente. Este hallazgo se mantiene detallado en `docs/TEST_FINDINGS_2026-08-04.md`.

## Criterio de salida recomendado

Antes de considerar QA aprobada por completo: instalar el navegador de Playwright y aprobar la matriz responsive. Luego repetir la suite sin `--keepdb` y el flujo E2E completo.
